# JTS Portfolio

A modern, high-performance developer portfolio built with React, Vite, and custom design aesthetics.

🌐 **Live Website**: [jtsdev.space](https://jtsdev.space)

## Features
- **Interactive Terminal Console**: Run commands in an interactive web shell.
- **Project Showcase**: Full breakdown of Web, Bot, and Automation developments.
- **Responsive Aesthetics**: Fluid layouts, ambient glows, and dark mode design.

## Tech Stack
- **Frontend**: React, JavaScript (ES6+), HTML5, CSS3
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Hosting**: Vercel
